# RGSG IHS G11 面谈预约 · 校内测试版

这是基于当前 G11 面谈排期逻辑制作的**校内测试原型**。它不是正式生产系统，但已经可以测试“家长预约 → 立即锁定 → 其他家长不可再约 → OP 后台查看/导出”的完整流程。

## 已写入的真实测试逻辑

- G11-1：对应 CAS 可用 + 班主任 Emma 可用。
- G11-2：对应 CAS 可用 + 班主任金辰昊的课表无冲突。
- G11-3：Ariel 的可用时间尚未提供，所以测试版暂不开放。
- Coco 关晓玉：按你的要求本轮另行预约，网站不开放 Coco 学生。
- Joyce / Willa / Emma / Layla 的候选时段来自当前排期工作簿；只有满足班主任重叠条件的时段进入候选池。
- 网站额外增加“G12 已锁定”和“发布给家长”两个开关。家长只看到 **已锁定 + 已发布** 的时段。
- 同一个 CAS 同一时间只有一个物理时段；即使该时段同时满足 G11-1 和 G11-2，也只能被一个家庭预约。

## 启动方法（无需安装第三方包）

需要电脑有 Python 3。

### Mac
双击 `启动测试版.command`。若 macOS 第一次阻止运行，可右键该文件 → 打开。

### Windows
双击 `启动测试版.bat`。

### 手动
在本文件夹打开终端：
`python3 server.py`
Windows 也可以：
`py server.py`

启动后终端会显示：
- 本机地址：`http://127.0.0.1:8000`
- 同一网络地址：例如 `http://192.168.x.x:8000`

同一 Wi‑Fi / 局域网内的同事可以用第二个地址一起测试。如果其他设备打不开，通常是电脑防火墙阻止了 8000 端口。

## OP / Admin 测试

默认管理员测试码：

`OP-TEST-2026`

进入后台后，先点击：

**一键生成测试发布时段**

系统会给 G11-1 / G11-2 的实际需求组各模拟发布少量可用时段。然后从“学生测试状态”里复制某位学生的测试预约码，在家长入口测试预约。

也可以直接点“家长端预览”。

## 家长测试码

见同文件夹：

`测试预约码.csv`

每位学生有一个测试码。正式版建议继续使用“每个家庭唯一链接/预约码”，不要把学生名单公开在家长页面。

## 测试建议

建议至少做这 5 个测试：

1. 两台设备同时尝试预约同一个时段，确认只有第一位成功。
2. 已预约学生再次预约，确认系统阻止重复预约。
3. 家长取消预约后，确认该时段重新回到可预约列表。
4. 用 Coco 学生预约码，确认系统提示“另行预约”。
5. 用 G11-3 学生预约码，确认系统提示“等待 Ariel 可用时间”。

## 重要限制

这是**校内测试版**：
- 数据保存在运行这台电脑的 `booking_test.db`。
- 不要把 8000 端口暴露到公网。
- 管理员测试码只是简单测试保护，不等同于正式账号权限系统。
- 目前没有短信/钉钉通知、正式身份验证、自动同步 WPS/G12 预约表、审计日志和云端备份。
- 正式给家长使用前，应迁移到带 HTTPS、登录/权限、数据库备份和服务器端安全配置的正式环境。

## 重置
Admin 后台点“重置全部测试数据”即可清空预约并取消发布。也可以停止服务器后删除 `booking_test.db`，下次启动会重新从 `data/seed.json` 初始化。
